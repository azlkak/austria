# Snow Place Like Austria — invitation

Animated one-page invitation for the snowboard trip to Austria (9–16 January).

- Black intro with a start button, then the illustrated ski map opens with an animation.
- Scrolling flies the camera across the map and reveals the invitation text line by line.
- Desktop only. Everything (illustrations, map, scripts) lives in `index.html`; fonts come from Google Fonts.

To publish: Settings → Pages → Deploy from a branch → `main` / root.
